# mxf_project

小台指期（MTX）三策略（開盤空、尾盤空、隔夜多）規則、資料與回測報告。

## 回測績效彙整（2020～2026）

彙整自 `report/` 底下各年度回測報告；每年度完整內容（各策略績效、跨年與資料稽核、重跑方式）請見各年度目錄的 README.md。

- 隔夜多開關：星期四關閉、星期五關閉。
- 成本情境：基準為單邊手續費 30 元＋1 點滑價，保守為單邊 50 元＋2 點；單位為新臺幣。
- 績效依**進場年**歸屬；最大已實現回撤依已平倉交易淨損益累計，未計入未實現損益。
- **2026 年為不完整年度**（資料至 2026-10-23），不可直接與完整年度比較。
